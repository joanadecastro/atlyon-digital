01.

Desafio

Clarificar uma landing page com demasiada competição visual.

A landing anterior concentrava hero, métricas, conteúdos e ações com um peso visual semelhante, tornando menos claro o que deveria ser visto primeiro.

O redesign reorganizou prioridades, leitura e percurso até à ação, em vez de se limitar a alterar o aspeto da interface.

02.

Reorganizar a Experiência

Selecionar, priorizar e dar hierarquia.

Problemas Identificados

A análise da landing revelou quatro áreas críticas na experiência: hierarquia, percurso, utilização da cor e chamadas à ação.

Solução 01

Foco

  • Criar níveis de leitura mais claros, distinguindo informação principal, secundária e complementar;
  • Dar maior protagonismo à proposta de valor e à ação principal logo nos primeiros momentos da página;
  • Aumentar o espaço negativo entre conteúdos para reduzir competição e orientar a atenção.
  • Criar níveis de leitura claros e previsíveis.
  • Destacar a proposta de valor e a ação principal.
  • Usar espaço negativo para orientar a atenção.
Solução 02

Sequência

  • Reorganizar os conteúdos numa narrativa progressiva, conduzindo o utilizador de contexto para compreensão e ação;
  • Apresentar primeiro a proposta de valor, seguida de prova, funcionamento e exploração das diferentes possibilidades;
  • Reservar conteúdos institucionais e de conversão para momentos posteriores, quando a plataforma já está contextualizada.
  • Organizar o percurso entre contexto, compreensão e ação.
  • Apresentar a proposta de valor antes da exploração.
  • Mover conteúdos institucionais para uma fase posterior.
Solução 03

Contraste & Identidade

  • Introduzir uma base escura capaz de unificar visualmente a experiência e criar maior continuidade entre secções;
  • Reservar o verde para ações, indicadores e pontos prioritários, reforçando a sua função dentro da interface;
  • Utilizar branco e tons neutros para estruturar diferentes níveis de informação e aumentar a legibilidade.
  • Usar uma base escura para dar continuidade à experiência.
  • Reservar o verde para ações e indicadores prioritários.
  • Estruturar os restantes níveis com branco e neutros.
Solução 04

Foco na Ação

  • Definir uma hierarquia clara entre ações primárias e secundárias, reduzindo a competição entre chamadas à ação;
  • Utilizar o verde como sinal consistente de ação prioritária, tornando mais previsível o comportamento da interface;
  • Integrar melhor os momentos de conversão no percurso, fazendo com que cada CTA surja no contexto adequado.
  • Distinguir claramente ações principais e secundárias.
  • Usar o verde como sinal da ação prioritária.
  • Integrar cada CTA no momento adequado do percurso.

Implementação Front-end

A implementação partiu do template Arsha / BootstrapMade como base estrutural. A personalização para LicitaNow incluiu a reorganização e adaptação das secções, composição visual, validação responsiva em 390, 430, 768, 1024 e 1440px, interações próprias e melhorias de navegação e acessibilidade.

Carrossel de princípios

O carrossel associa o estado JavaScript às classes visuais left, center, right e hidden, mantendo a navegação circular e atualizando aria-hidden.

index.html · linhas ~719–737
function updateCarousel() {
  cards.forEach((card, index) => {
    card.classList.remove('left','center','right','hidden');
    card.setAttribute('aria-hidden', String(index !== current));

    if (index === current) {
      card.classList.add('center');
    }
    else if (index === (current - 1 + cards.length) % cards.length) {
      card.classList.add('left');
    }
    else if (index === (current + 1) % cards.length) {
      card.classList.add('right');
    }
    else {
      card.classList.add('hidden');
    }
  });
}
